# Store Interesting Wallet Evidence From Historical Replay

Interesting wallets are stored as Robinhood Chain-specific records, and every reason a wallet is worth watching is a separate `wallet_evidence` event keyed by a deterministic id (kind, chain, pair, wallet). The historical replay `reconstruct` command derives `historical-runner-buy` evidence for pairs manually labelled `runner` straight from the reconstructed Robinhood RPC swap logs, so wallet evidence never depends on live trading data. Manual `wallet_tags` and `pair_tags` (`interesting` or `ignored`) let a human override or suppress entries. Wallet evidence, interesting wallets, and manual tags are all inspectable through `npm run replay-pairs -- wallets` and the HTML/CSV simulation reports. This extends ADR-0009 and follows ADR-0011's manual-runner replay approach; consuming this evidence in trade-setup ranking is deferred.

# Send Optional Telegram Alerts With Persisted History

The live monitor will send Telegram alerts for new trade setups, simulated fills, stop losses, 2x take profits, repeated data-source failures, and a daily summary for the previous Europe/Paris day. Telegram is an optional adapter configured through `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID`; missing credentials disable only that adapter unless a command opts in with `--require-alerts`. This follows ADR-0004 now that live DEX Screener monitoring is proven. Each delivered alert is recorded in the existing `alert_history` table keyed by a deterministic id, and the dispatcher records only after a successful send, so repeated scans and restarts never resend an alert. Repeated-failure alerts fire once an adapter has failed at least three consecutive scans and at most once per hour per adapter.
